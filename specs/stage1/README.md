# Stage 1: Detailed Specifications

## Purpose
Building upon Stage 0's high-level architecture and requirements, this stage provides detailed technical specifications for each component in the dashboard system.

## Reference Repository

- Next.js 15.1.3 frontend with standalone output (port 3000)
- FastAPI backend with DuckDB (port 8000)
- ZarrinPal payment data schema
